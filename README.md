# 检修剂量场仿真系统

核电厂大修检修作业的剂量场仿真与 ALARA 分析工具。浏览器端运行,TypeScript + WebGPU(计算着色器),厂房模型与方案持久化在 IndexedDB。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生产构建 (dist/)
npm test         # 物理对标与功能测试
```

首次打开自动生成一座三标高层反应堆厂房模型(-4m 堆坑层 / 0m 主设备层 / +8m 操作大厅)和一套巡测数据,之后所有修改自动保存到 IndexedDB。模型结构升级时旧存档自动重建。

## 页面

| 页面 | 功能 |
|---|---|
| 厂房模型 | 按房间/标高组织,墙板设备管道为几何体拼装,每块填材料与密度(混凝土/钢/铅/水);点击构件可改材料 |
| 源项管理 | 点源/管线线源/设备内表面面源,按 Co-60/Co-58/Cs-137 录活度,按作业日期自动衰变修正;巡测对标与源项标定 |
| 屏蔽布置 | 铅毯/铅砖墙拖入场景摆放(Shift 拖动升降),多方案管理,摆完只重算受影响区域 |
| 剂量场视图 | 任意剖切面剂量率热图,对数色标+等剂量线,悬停读数并列出贡献最大的源,屏蔽前后差值图 |
| 作业路径 | 三维点击布点,每段带停留时间和人数,积出个人/集体剂量,超日限值标红;自动低剂量寻路与最短路线对比 |
| ALARA 报告 | 多方案并排比选:铅用量、搭拆剂量、节省剂量、净收益,导出 HTML 报告 |

## 物理模型

点核积分:对各向同性点源,场点处第 i 条伽马线注量率

```
φ_i = A·Y_i / (4πr²) · B_i(μt) · exp(-μt),   Ḋ = Σ_i φ_i · (E·μ_en/ρ 换算)   [Sv/h]
```

- 衰减:射线逐屏蔽体累加各材料平均自由程数 μt(slab 法求 AABB 穿行长度)
- 累积因子:Berger 形式 B = 1 + a·μt·e^(b·μt),取主导屏蔽材料系数
- 线源/面源离散为点源集合(活度守恒),衰变按 A(t)=A₀·2^(-Δt/T½)
- 巡测标定:加权非负最小二乘(坐标下降+岭正则化)反推各源活度比例因子

## 精度验证 (tests/physics.test.ts)

- 裸点源 vs 解析点核公式:偏差 < 0.1%
- Co-60 剂量率常数落在文献范围(0.30~0.37 mSv/h @1m·GBq)
- **点源+单层平板(铅/混凝土/钢/水,含斜射)vs 手算点核公式:偏差 < 1%**
- 衰变修正:半衰期整数倍活度精确减半
- 线源/面源离散活度守恒
- GPU(WGSL)与 CPU 使用同一份系数表与同一公式,CPU 参考实现即对标基准

## 性能设计

- WebGPU 计算着色器,每体素一个线程;无 GPU 时自动回退 CPU 快速内核
- 分帧计算:每帧预算 12ms,界面不卡
- 渐进细化:步长 4→2→1 三级,粗结果立即全场可见后逐步细化
- 局部重算:拖动铅毯只重算受影响 AABB 区域
- 参考:1036 个离散点源 × 37 个屏蔽体 × 8.3 万体素,CPU 兜底约 40s(GPU 上亚秒级)

## 已知简化(工程估算级)

- 屏蔽体统一为轴对齐盒;容器用 6 壁板拼壳,禁止嵌套盒(会重复计衰减)
- 管道钢壁+充水按等效密度 2.0 g/cm³ 抹平
- 多材料屏蔽的累积因子取主导层 Berger 系数
- 寻路在房间/门洞/楼梯逻辑图上进行,不做碰撞体素级检查
